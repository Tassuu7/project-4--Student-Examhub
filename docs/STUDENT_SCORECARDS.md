# Student Examination Scorecards & Question-by-Question Evaluation

## Overview
The ExamHub evaluation engine provides instantaneous, deterministic grading with comprehensive question-level reviews for candidates and instructors.

## Key Capabilities
1. **Interactive Candidate Scorecards**:
   - Question-by-question breakdown showing candidate response vs. correct answer.
   - Mark allocation, percentage score, letter grade (A+ through F), and institutional rank.
   - Detailed pedagogical explanations for each question item.
2. **Defensive UI Rendering**:
   - Guaranteed null-safe review item handling.
   - Clear indicators for unanswered, partially correct, and fully correct answers.
