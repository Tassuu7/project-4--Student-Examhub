# Role-Based Access Control & Navigation Architecture

## Overview
ExamHub enforces strict Role-Based Access Control (RBAC) across three primary user archetypes:

1. **Principal / Executive**:
   - High-level institutional governance and department pass rate analytics.
   - Examinations oversight and curriculum coverage audits.
   - Zero extraneous clutter (certificates delegated to teachers).

2. **Teacher / Instructor**:
   - End-to-end examination lifecycle management.
   - Question bank curation with Bloom's taxonomy tags.
   - Student performance monitoring and subjective feedback.
   - Live continuous proctoring and certificate issuance authority.

3. **Student / Candidate**:
   - Clean, focused test-taking interface with live auto-save.
   - Instant scorecard inspection and feedback review.
   - Verifiable digital certificates repository.
